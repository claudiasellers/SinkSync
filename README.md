# SinkSync

A mobile-first dishwashing companion built to lower task-initiation friction, sustain momentum, and make stopping a deliberate, guilt-free choice.

## Run locally

No dependencies or build step are required.

1. Download the repository as a ZIP and extract it.
2. Double-click `index.html`.

For the most reliable browser behavior, run a tiny local server from the folder:

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## Included

- Scrub-gesture “one fork” motor primer
- Session timer and item counter
- Generative Web Audio soundtrack that gains layers with momentum
- Passive drops and collectible unlocks
- Persistent UGH circuit breaker
- Guilt-free tap-out flow
- 60-second Boss Fight with a rare reward
- Local progress persistence
- Reduced-motion support and keyboard-accessible controls
- Responsive layouts for phone and desktop

## Privacy

SinkSync has no accounts, analytics, backend, or external API calls. Progress is stored only in your browser with `localStorage`. Clear the browser’s site data to reset it.

## Audio

Browsers require an interaction before audio can begin, so sound starts after the first tap. The soundtrack is generated in the browser and can be muted at any time.
